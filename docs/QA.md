## 아직 확인하지 못한 범위

- 실제 Android 기기 / Samsung Internet에서의 실행. 이번 모바일 검수는 Chrome 내 폭을 조정한 뷰포트 검사입니다.
- 실제 인증·DB·이메일 발송·개인정보 저장·신청 프로필 조회: 미연결이며 작동하는 것으로 표시하지 않았습니다.
- SQL 초안은 실제 DB에 적용하거나 RLS 통합 테스트를 실행하지 않았습니다.

## 공개 배포 후 재검수 결과

- GitHub Actions build/deploy 성공. Pages가 반환한 실제 공개 URL로 접속, 별도 로그인 요구 없음.
- PC: 한글, CSS·JS, hero 이미지 정상. 원본 naturalWidth 864 / naturalHeight 1536, object-fit contain 확인.
- 저장소 파일 15개의 Git blob 해시를 로컬 원본과 비교하여 모두 일치. 여성 캐릭터도 원본 바이트 일치.
- 신청 CTA·단계 이동, 빈 필수값 7개 오류·첫 필드 포커스, 드롭다운 및 전체 가상 입력 흐름 정상.
- 서울+경기 복수 선택, 지역무관 선택 시 개별 지역 해제, 이후 부산 선택 시 지역무관 해제 정상.
- 체험 제출 완료 화면 표시, 작성률 100%, 초기화 후 0%·전체 필드 비움 확인.
- 프로필 조회 준비 상태 안내, 개인정보 모달·Escape 닫기 정상.
- 공개 URL을 로드한 360px / 412px iframe에서 이미지·입력폼·드롭다운·지역 복수 선택·고정 진행도 확인. 내부 content width는 스크롤바 제외 345px / 397px이며 scrollWidth와 같아 가로 넘침 없음.
- 모바일 스크롤 카드 opacity=1 및 visible 클래스, 은은한 등장 애니메이션 확인.
- 실제 Android 기기는 미검수. 모바일 결과는 Chrome CSS 뷰포트 검수임.
- 백엔드가 없으므로 테스트는 체험 UI의 동작만 검증하며 실제 접수·인증·조회 성공을 의미하지 않음.

검수용 `qa-mobile.html`과 이 문서는 배포용 `dist/`에서 제외합니다.
